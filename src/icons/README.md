# Icons

The JetBrains icons of the app's interface (the owner's choice, 2026-11-12): the IntelliJ Platform's new UI icons,
from [`platform/icons/src/expui/`](https://github.com/JetBrains/intellij-community/tree/master/platform/icons/src/expui)
of `JetBrains/intellij-community`, commit `b81be017f1f8eed0574e0718e318c4483c02d255`. Each file keeps its own notice,
"Copyright 2000-<year> JetBrains s.r.o. and contributors. Use of this source code is governed by the Apache 2.0
license."; the licence's text is [LICENSE.txt](LICENSE.txt), and the project's notice, which Apache 2.0 asks to carry
with its work, is [NOTICE.txt](NOTICE.txt).

- `expui/` keeps the upstream folders and names, and only the dark variants (`_dark.svg`): the app is dark only.
- The files are copied unchanged. A new icon is copied the same way, then named in `icons.ts`.
